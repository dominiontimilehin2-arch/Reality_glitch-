# Reality_glitch-
Your screen is not behaving normally.
🌀 Reality Glitch

The screen is lying. Can you figure out why?

Reality Glitch is a strange, interactive mini-game where normal website rules stop making sense. Explore unexpected interactions, solve unusual puzzles, and discover hidden secrets.

🎮 The Game

- 🌀 Level 1 — The Lying Button: Don't trust everything you see.
- 🪟 Level 2 — The Escaping Window: Find a way out.
- ⚡ Level 3 — The Broken Reality: Discover the secret ending.

✨ Features

- Designed for mobile phones and desktop browsers
- Interactive puzzles and unexpected surprises
- Strange visual effects
- A mysterious digital-world atmosphere
- Free to play in your browser
